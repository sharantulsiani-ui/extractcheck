# Contributing

Before accepting public contributions, enable private vulnerability reporting
and add a public code of conduct.

For local development:

1. Use Python 3.11 or newer.
2. Add only synthetic fixtures and evidence.
3. Never commit source documents, private hashes, absolute machine paths,
   emails, model files, parser caches, or runtime outputs.
4. Preserve source-read-only behavior and exact provenance.
5. Add a regression test for every safety or scoring change.
6. Run the unit suite, synthetic proof and release audit before proposing a
   change.
